# Chapter 12 - 1

동기화 -  동기화란 협력적으로 실행되는 프로세스들의 수행 시기를 맞추는 것

- 실행 순서 제어를 위한 동기화: 정해진 순서대로 실행되게 하기
- 상호 배제를 위한 동기화: 동시에 접근하면 안 되는 자원에 여러 프로세스가 동시에 접근하지 못하게 막기

레이스 컨디션 - 여러 프로세스가 공유 자원에 동시에 접근할 때 실행 타이밍(컨텍스트 스위칭)에 따라 결과가 달라지거나 틀려지는 문제

임계 구역 - 공유 자원에 접근하는 코드 영역. 두 개 이상의 프로세스가 임계 구역에 동시에 진입하면 안 됨

임계구역 문제를 해결하기 위한 중요한 원칙

- 상호배제 - 생산자 소비자 문제
- 진행
- 유한대기

# Chapter 12 - 2

동기화 기법

- 뮤텍스락 - lock + acquire()(잠그기) / release(풀기) 두 함수로 구현 → 잠금이 풀렸는지 계속 확인 busy wait
- 세마포어 - 뮤텍스를 확장해서 공유 자원이 여러 개인 상황에도 쓸 수 있게 만든 도구 / S(사용 가능한 자원 개수) + wait()(자원 있는지 확인 후 진입) / signal()(자원 반납, S 증가) 두 함수로 구현
- 모니터 - 모니터는 공유 자원과 이를 다루는 연산(인터페이스)을 하나로 묶고, 모니터 안에는 항상 프로세스 하나만 진입 가능하게 해서 상호 배제를 해결해줌
