# chapter 14 가상 메모리
## 14-1 연속 메모리 할당

연속 메모리 할당이란?
 
 프로세스는 자신만의 메모리 공간을 할당받아 연속된 메모리 공간에 배치된다 이렇게 연속적인 메모리 공간에 프로세스 들이 적재되는것을 연속 메모리 할당이라고 한다.

이렇게 메모리에 연속적으로 적재된 프로세스 들중에 실행되지 않는 프로세스들도 존재한다.   
이들이 메모리 공간을 차지하고 있는것은 굉장히 비효율적이다. 

그래서 실행되지 않는 프로세스를 임시로 보조 기억장치로(swap space) 적재하고 원래 메모리공간에서 삭제 시키고(swap out) 새로운 프로세스를 적재하는것(swap in)을 **스와핑** 이라고 한다.

### 메모리 할당 방법 

메모리가 스와핑을 거치면서 빈공간이 생기면 그공간에도 프로세스가 적재 되어야한다.

빈공간에 할당하는 방법 
1. 최초 적합
2. 최적 적합
3. 최악 적합

 의 방법이 존재한다 하지만 이 방법들은 **외부 단편화**를 발생시킨다.

 이를 해결하기위해 압축하는 방법을 사용하지만 압축하는 과정에서 시스템이 중지 되고 많은 오버헤드를 발생시킨다.

 ## 14-2 페이징을 통한 가상 메모리 관리

 프로세스를 메모리에 연속적으로 할당하는 방법은 물리 메모리보다 큰 프로세스를 적재 하지못한다.

 이럴때 **가상 메모리** 라는것을 사용한다 

 가상 메모리 기법에는 **페이징**과 **세그먼테이션**이 있다.

### 페이징

페이징은 프로세스와 메모리 공간을 일정한 크기로 분할하고
그리고 분할된 프로세스(페이지)를 불연속적으로 분할된 메모리 공간(프레임)에 할당하는것이다.

페이지는 프레임에 불연속적으로 할당되어있기 때문에 cpu가 실행하는데 어려움을 겪을수 있다 그렇기 때문에 **페이지 테이블**을 사용해서 논리주소와 물리주소가 연속되게 저장한다.

### 페이지 교체 알고리즘

페이지 폴트가 적게 일어나게 페이지를 교체하는것이 좋은 페이지 교체 알고리즘이다.

1. FIFO 페이지 교체 알고리즘
2. 최적 페이지 교체 알고리즘
3. LRU 페이지 교체 알고리즘   

 등이 있다. 최적 알고리즘은 이론상의 알고리즘이다.

### 프레임 할당 방법

1. 균등 할당
2. 비례 할당
3. 동적 할당 방식(페이지 폴트 빈도, 작업 집합 확인 방법)



## 질문 

내부 단편화를 해결하려면 페이지의 크기를 적당한 크기로 분할해야하는데 이것도 방법이 다른가?
x86-64 Linux → 기본 페이지 크기 보통 4KB, 큰 페이지(2MB, 1GB)도 지원  
Windows → 일반적으로 4KB 페이지를 사용  
macOS → Apple Silicon에서는 일반적으로 16KB 페이지를   사용하고, 일부 Intel Mac은 4KB를 사용
