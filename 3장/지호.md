## 소스 코드와 명령어
우리는 소스코드로 프로그램을 작성함 
그럼 컴퓨터가 우리가 작성한 소스코드 이해 가능? 

불가능함 

### 저급 언어와 고급 언어

우리가 작성하는 소스코드는 일반적으로 **고급 언어**임, 컴퓨터가 이해하는 언어는 **저급 언어**임
우리가 작성한 코드들을 번역을 해서 컴퓨터는 이해를 함 

저급 언어에는 0, 1 로 이루어진 **기계어**, 010101 같은 명령어를 사람이 읽기 쉽게 번역한 **어셈블리어** 가 존재함.



### 고급 언어를 저급 언어로 변환 하는 방법
**컴파일**, **인터프리트** 두개의 방법이 있음  
컴파일은 소스코드를 전부 저급 언어로 변환 하는 방식임.  
인터프리터는 한줄식 코드를 저급 언어로 변환 하는 방식임.


**링킹** 컴파일 할때 목적파일이 생성되는데 그것들의 코드와 참조를 서로 연결해주는 과정임.

## 명령어의 구조

### 오퍼랜드와 연산코드  
명령어는 오퍼랜드와 연산 코드로 구성됨
연산 코드는 명령어가 수행할 연산 오퍼랜드는 연산에 필요한 데이터를 저장하는 장소.  
ex) 더하라 100을 에서 더하라는 연산코드 100을 저장하는 장소가 오퍼랜드임 메모리 주소나 레지스터 주소가 담김

그래서 명령어 안에는 오퍼랜드가 존재하지 않을수도 있고 여러개 존재할수도 있음  
오퍼랜드 갯수에 따라 x-주소명령어로 불림

연산코드는 4가지의 유형으로 나뉜다   
1.데이터 전송  
2.산술/논리연산    
3.제어흐름 변경   
4.입출력 제어  

오퍼랜드 필드에는 메모리 주소나 레지스터 주소를 입력한다고했는데 그 이유가 비트수의 한계 때문 

연산에 사용하는 데이터가 있는 주소를 **유효주소** 라고함

즉시 주소 지정 방식 - 데이터를 오퍼랜드 필드에 직접 입력하는 방식  
직접 주소 지정 방식 - 유효주소를 오퍼랜드 필드에 입력하는 방식  
간접 주소 지정 방식 - 유효주소가 담긴 주소를 필드에 입력하는 방식  

밑으로 내려갈수록 연산할수있는 데이터의 크기가 커지지만 접근하는데 걸리는시간이 오래 걸림.
