# cpu
## ALU 와 제어장치

ALU 가 받는 정보: 레지스터에서 피연산자를 받고 제어장치에서 수행할 연산에 대한 제어신호를  받아서 연산을 진행함.  

ALU 가 내보내는 정보: 연산을 진행한 결과값과 **플래그** 를 내보냄.  

플래그란? 연산 결과에 대한 추가적인 정보.  
플래그의 종류  
부호 플래그 - 연산한 결과의 부호  
제로 플래그 - 연산 결과가 0인지   
캐리 플래그  - 올림수나 빌림수가 발생했는지  
오버플로우 플래그 - 오버플로우가 발생했는지  
인터럽트 플래그 - 인터럽트가 발생했는지   
슈퍼바이저 플래그 - 커널모드 인지 사용자 모드인지  

플래그들은 플래그 레지스터에 저장됨


제어 신호가 받아들이는 정보: 클럭신호, 해석해야할 명령어, 플래그 레지스터의 플래그 값, 제어버스로 온 신호

## 레지스터
레지스터

레지스터란? CPU 내부에서 프로그램 실행에 필요한 값들을 임시로 저장하는 작은 저장장치.

레지스터 종류


프로그램 카운터   
명령어 레지스터   
메모리 주소 레지스터   
메모리 버퍼 레지스터  
플래그 레지스터  
범용 레지스터  
스택 포인터  
베이스 레지스터  

특정 레지스터를 이용한 주소 지정 방식

스택 주소 지정 방식
스택 포인터를 이용하여 스택에 있는 데이터에 접근하는 방식.

변위 주소 지정 방식
레지스터에 저장된 값과 명령어에 주어진 값을 더해서 실제 데이터의 주소를 구하는 방식.

## 명령어 사이클과 인터럽트

CPU는 명령어를 처리할때 정형화된 차례를 따라감. 
1. 인출 사이클: 명령어를 메모리에서 CPU로 가져오는 단계  
2. 실행 사이클: 가져온 명령어를 실행하는 단계
3. 간접 사이클: 메모리 접근이 더 필요한 경우 메모리에 접근하는 단계

인터럽트: CPU의 작업을 방해하는 신호 **동기 인터럽트**와 **비동기 인터럽트**로 나뉨

**동기 인터럽트**는 폴트, 트랩, 중단, 소프트웨어 인터럽트가 있음  
**비동기 인터럽트**는 막을수있는 인터럽트와 막을수 없는 인터럽트가 있음
