## 메모리와 캐시 메모리
### RAM의 특징과 종류

RAM은 실행할 프로세스를 저장한다. 
용량이 크면 클수록 많은 프로그램을 저장 할수있기 때문에  동시에 프로그램을 실행 할때 빠르게 실행 가능하다.

RAM의 종류
    - DRAM: 저장된 데이터가 동적으로 사라지는 RAM  
    - SRAM: 저장된 데이터가 사라지지 않는 RAM  
    - SDRAM: 클럭 과 동기화 되어 발전된 형태의 DRAM    
    앞에 DDR x SDRAM 은 대역폭을 늘린것 2^x 배 데이터를 많이 주고 받을수 있음

### 메모리의 주소 공간

물리주소: 메모리, 하드웨어가 사용하는 주소이다.  
논리주소: CPU와 실행중인 프로그램이 사용하는 주소 이다.  

MMU:논리 주소와 물리 주소를 변환 해주는 장치

### 메모리 보호 기법 

물리 주소의 충돌을 방지 하기 위해서 **한계 레지스터**를 사용해 논리 주소의 크기를 설정한다.
### 캐시 메모리

SRAM을 사용해서 자주 사용하는 데이터를 저장하고 사용한다.

그렇다면 필요한 데이터가 뭔줄알고 저장하는가?

**참조 지역성의 원리**를 사용해서 데이터를 저장한다.

참조 지역성의 원리에는 **시간지역성**과 **공간지역성**이 있다. 

## 질문 
클럭과 동기화 되었다는게 어떤의미이고 어떤부분에서 더 좋아진것인가?  

SDRAM은 시스템 클럭에 맞춰 동작하는 DRAM이다. 그래서 CPU가 메모리의 동작 시점을 정확히 예측할 수 있어 대기 시간이 줄고, 여러 메모리 작업을 파이프라인 방식으로 효율적으로 처리할 수 있어 성능이 향상된다.


한계 레지스터보다 논리 주소가 클때 인터럽트를 발생시켜서 실행을 중단한다고 했는데 처음부터 잘 설정할수없나?

처음부터 한계 레지스터는 잘 설정한다. 그런데 프로그램에서 허용된 범위를 벗어나는 요청을 보냈을때 인터럽트가 발생한다.

시간지역성과 공간 지역성중에 어떤것에 가중치를 더 두는가?

가중치를 두기 보다는 같이 사용해서 캐시메모리를 구성한다.
