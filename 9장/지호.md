# 9장

## 운영체제 

### 9-1 운영체제란?

프로그램 실행에 필요한 요소들을 **시스템 자원** 이라고 한다.

프로그램에 필요한 시스템 자원을 할당하는것을 **운영체제**가 한다.

메모리는 사용자 영역과 커널영역으로 나뉘는데 커널영역에 운영체제가 적재된다.

>Q. 커널 영역과 사용자 영역은 어떤 기준으로 나뉘며 뭐가 있고 운영체제의 크기는 얼마나 되는것일까?
```notion 

A. 사용자 영역과 커널 영역은 프로그램이 사용할 수 있는 권한과 메모리 공간을 분리하여 보호하기 위해 나뉜다.

사용자 영역에는 일반적인 응용 프로그램과 그 프로그램이 사용하는 메모리가 적재되고, 
커널 영역   
커널 코드 
프로세스 관리 정보  
PCB        
메모리 관리 정보  
파일 시스템 정보      
장치 관리 정보   
커널 스택   
기타 커널 자료구조   
```

>Q. 메모리 누수현상이 무엇일까?

```notion 
A.프로그램이 동적으로 할당한 메모리를 더 이상 사용하지 않으면서도 반환하지 않아 메모리가 계속 점유되는 현상이다.

예를 들어 프로그램이 계속해서 메모리를 할당하지만 사용이 끝난 메모리를 해제하지 않는다면:
메모리 할당  
   ↓  
메모리 사용.  
   ↓  
사용이 끝남  
   ↓   
메모리 해제 X  
   ↓   
또 메모리 할당  
   ↓  
메모리 사용량 계속 증가

이런 현상이 계속되면 사용할 수 있는 메모리가 부족해져 프로그램의 성능이 떨어지거나 프로그램이 종료될 수 있다
```


### 9-2 운영체제의 큰그림

운영체제가 제공하는 서비스 중에 프로그램이 안전하게 실행되고 자원에 접근 하는 기능을 담당하는 핵심 서비스 부분을 커널 이라고 한다.

커널에 포함 되지 않는 부분중에 사용자 인터페이스 서비스가 있다.

사용자 인터페이스 는 그래픽 유저 인터페이스와 커맨드 라인 인터페이스로 나뉜다.

>Q. 그래픽 유저 인터페이스는 커맨드 라인 인터페이스에 그래픽을 입힌것인가?
```notion 
GUI가 버튼을 눌렀을 때 내부적으로

버튼 클릭
 ↓
"mkdir test"라는 명령어 생성
 ↓
쉘

이렇게 동작하는 것은 아니다.

GUI는 운영체제 내부에 API를 사용해서 작동한다.

```
프로그램이 직접 자원에 접근하고 조작하게 된다면 프로그램끼리 쉽게 충돌할것이다.  
그래서 프로그램이 자원에 접근할때 운영체제를 거쳐서 접근한다.  
이것을 이중모드를 통해 구현한다.

이중모드는 사용자 모드와 커널모드로 나뉜다.  
거의 모든 프로그램은 운영체제 서비스를 사용하기 때문에 사용자 모드와 커널모드를 왔다갔다 한다.

운영체제의 서비스는 프로세스 관리, 자원 접근 및 할당, 파일 시스템 관리 등을 제공한다. 


>Q. 가상머신에서 다른 운영체제를 사용하면 자원에 접근하는 방식이 다를수도 있는데 이를 어떻게 해결하는가?
```notion 
A.
가상머신에서는 하이퍼바이저가 실제 하드웨어와 가상 운영체제 사이에서 중간 역할을 한다.

가상머신에서 실행되는 운영체제를 게스트 운영체제라고 한다.

게스트 운영체제는 실제 하드웨어에 직접 접근하는 대신 가상 CPU, 가상 메모리, 가상 디스크 등의 가상 하드웨어를 사용한다.
```
